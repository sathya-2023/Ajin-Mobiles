# Ajin Mobiles

A responsive, single-page storefront site for Ajin Mobiles (Vallioor). It highlights featured products, services, gallery, and contact details with a clean, modern layout.

## Features
- Responsive navigation with mobile menu
- Hero section with brand messaging
- Product, services, and gallery sections
- Contact section with call and WhatsApp actions
- Smooth scrolling and subtle animations

## Project Structure
```
Ajin-Mobiles/
  assets/
    imges/            # Images used across the site
  css/
    styles.css        # Main styles
  js/
    script.js         # Navbar and gallery animation logic
  index.html          # Main page
```

## Run Locally
Open index.html directly in your browser, or use a simple local server:
- VS Code: use the Live Server extension
- Python: `python -m http.server`

## Customize
- Hero background: update `.hero` in css/styles.css
- Content and sections: edit index.html
- Colors and typography: update CSS variables in css/styles.css

## Notes
- Image paths are under assets/imges/
- Keep filenames and paths consistent with the HTML and CSS references
